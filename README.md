# _a-blog-out-of-deep-space_

Long name? It's just `a-b<TAB>` away :D

An opinionated\* web-server designed to serve static sites produced by the likes of `hugo` with minimal CPU load

## \*Opinions

- All files being served are small and you're fine with them all eagerly being loaded into memory along with compressed variants on launch x)
